還沒接上共用資料庫

這個網頁是給大家一起即時投票用的，所以票數必須存在一個共用的地方。沒有它的話，你只會看到自己那一票，投票也就沒有意義了。

  1. 到 console.firebase.google.com 建一個專案
  2. Build → Realtime Database → 建立資料庫，位置選 asia-southeast1
  3. 專案設定 → 一般 → 新增網頁應用程式，抄下 apiKey 和資料庫網址
  4. 把兩個值填進 index.html 最上面的 FIREBASE，重新部署

想先試試看的話，也可以展開下面的「設定」暫時填進去 —— 但那只存在你這台裝置，正式上線還是要寫進原始碼，別人打開才會生效。

⚠️ secret 放前端等於公開，只用測試金鑰。瀏覽器直打 TDX 多半被 CORS 擋，需自架 proxy。抓不到會自動退回內建時刻表。
